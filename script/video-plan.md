# 视频方案：《当智慧像电一样便宜》

## 规格（待确认）

- 时长：约 2 分 30 秒（口播约 650 字，由正文压缩而来）
- 画幅：1080×1920 竖屏（备选 1080×1440，即 3:4）
- 帧率：30fps（运镜多的话可以上 60fps）

## 视觉系统

**核心母题**：继承账号封面的灵魂——**渺小的人 × 巨大的物**。

| 层 | 做法 |
|---|---|
| 色彩 | 单一主色：电光紫 `#5B2EFF`，深紫 `#1E0B5C`，纸白 `#F3F0EA`，墨黑 `#111`。不加第二种彩色 |
| 3D 层（巨物） | 纪念碑尺度的几何体：哑光黏土 + 半透明紫玻璃材质，体积光、雾、景深、电影颗粒、轻微色差。目标是 UE5 Lumen 那种全局光质感 |
| 2.5D 层（人） | 小人全部是手绘墨线排线风格的"纸片人"，插在 3D 空间里做视差，和封面插画的人物同一套语言 |
| 字体 | 超粗黑体大字，关键词染紫，砸入式动效；数字用滚动计数器 |
| 运镜 | 缓慢推拉、升降、绕巨物环绕；转场用形状匹配剪辑（螺旋 → 晶格 → 光环 → 光柱 → 门） |

## 制作路线

**推荐路线 A：全部在这里用代码渲染**
- 3D：Three.js / WebGL，后期叠 Bloom、景深、体积雾、胶片颗粒、暗角
- 2.5D：墨线小人做成透明贴图卡片，放进 3D 场景做视差
- 动效字：代码驱动，中文字形可以逐字精确控制
- 输出：无头 Chromium 逐帧渲染，ffmpeg 合成 MP4
- 优点：端到端由我交付，品牌风格统一，字幕和数字绝对准确
- 上限：能做到高端 motion design 的质感，但不是 UE 的写实电影渲染

**可选路线 B：AI 视频补主镜头**
- 我按分镜写好每个镜头的首帧图提示词和视频提示词（可灵 / 即梦 / Veo 等）
- 你生成几个主镜头，我再把它们和代码渲染的字幕、数据动画、转场合成在一起
- 优点：更接近 UE 电影感
- 代价：镜头之间的一致性要靠多跑几次来挑
