# 视觉规范（取自《当智慧像电一样便宜》v2）

所有新选题（视频、图文）都按这份做，保证账号视觉统一。源码参考：`src/style.css`、`src/lib/overlay.js`、`src/shots/walls.js`、`src/shots/door.js`。

## 颜色

| 名称 | 色值 | 用途 |
|---|---|---|
| 电光紫 | `#5B2EFF` | 标题上方的短条、序号、紫色硬阴影、圆点 |
| 亮紫 | `#6A3BFF` | 正文里的重点词（`.p`） |
| 浅紫 | `#8E6BFF` / `#A98DFF` / `#B69CFF` | 深色底上的重点词、照片标签里的重点 |
| 纸白 | `#F6F3EE`（片尾底色 `#F2EEE7`） | 旁白框、数据面板、片尾 |
| 墨黑 | `#15121b` | 文字、描边、硬阴影、小人 |

场景底色是带紫色光晕的淡紫灰渐变，加暗角（约 0.42）、胶片颗粒（约 0.03）、暗部网点、墨线描边。

## 字体

- 中文：Noto Sans SC。标题用 900，正文用 500 或 700。
- 数字：Anton（`.num`），重点数字同时上紫色。
- 英文小标：Inter 800，字距 0.26em，紫色。

## 标题区（每个画面都一样）

- 紫色短条 96×12，位置 (76, 204)。
- 序号行 64px：Anton 紫色序号 + 空格 + 900 粗的关键词，例如「**01** 疾病」。
- 大字放在 (72, 336)，字号 124–170，行高 1.04，墨黑。重点词用紫色。文字带纸白外发光 `0 0 30px rgba(246,243,238,.95)`。
- 动画：每行文字从遮罩下方滑上来。

## 旁白框（capBox，最核心的元素）

- 纸白底，5px 墨黑描边，内边距 22 / 32 / 26。
- 硬阴影 `14px 14px 0`：叙述用墨黑，强调或结论用电光紫。
- 旋转 ±1.2°，相邻两个框一正一反。
- 字号 54，字重 900，行高 1.34。宽 936，常用位置 x 72，y 1180 / 1430。

## 数据面板

和旁白框同一种样式：紫色硬阴影，内边距 30 / 20 / 24，宽 940。顶部是 36px 900 的面板标题，里面放图表或示意图。

## 照片面板

- 6px 墨黑边框，紫色硬阴影 16px，旋转 ±3–4°。
- 顶部贴一条半透明纸胶带。
- 下方是墨黑标签，白字 26px 700，标签里的重点用 `#A98DFF`。

## 墨线小人

用 2.5D 墨线小人（`src/lib/figure.js`）表现尺度和情绪，比如站在巨物前仰望、举手。

## 漫画后期

- 墨线描边：对亮度做 Sobel 边缘检测。
- 暗部加网点。
- 冲击时刻加集中线。
- 再叠加辉光、轻微色差、颗粒、暗角。

## 片尾

纸白底 → 紫色短条 → 132px 主标题（重点词紫色）→ 46px 副标题 → 「● Coo-Coo出海Ai实验室」（紫色圆点 + 40px 900 墨黑字）→ 24px 灰色来源。

## 节奏

不配音，全部靠大字讲故事。纯音乐，重音卡在画面事件上。

## 图文（3:4，1080×1440）怎么套

- 标题区整体上移，短条放在 y≈110。
- 中间放一个数据面板或示意图。
- 下面放两个旁白框：墨黑阴影的写事实，紫色阴影的写「对你意味着」。
- 左下角放「● Coo-Coo出海Ai实验室」，右下角放页码。
